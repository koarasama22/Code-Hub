品質について
  • 4K・120 FPS・96 kHzは「要求値」です。実際の品質はカメラ、マイク、PC、ブラウザーが対応する範囲に制限されます。
  • このページは端末内で映像・音声を再生します。配信サーバーへの送信や、インターネット上への公開は行いません。
  • マイク音声をスピーカーで再生すると、ハウリングやエコーが発生することがあります。音声再生にはヘッドホンをおすすめします。
  • カメラ・マイクへのアクセスにはHTTPSまたはlocalhostが必要です。HTMLファイルを直接開く場合、ブラウザーによっては動作しないことがあります。
  • プレビュー右上の「フルスクリーン」またはキー F で映像をフルディスプレイ表示できます。解除は Esc です。
